# TeleMetric: Customer Retention & Churn Intelligence

[![Live Demo](https://img.shields.io/badge/Live_Demo-Open_App-8e44ad?style=for-the-badge)](https://telemetric.streamlit.app/)

TeleMetric is an interactive, decision-support dashboard built to analyze customer behavior, predict churn, evaluate model risk, and simulate retention strategies. It bridges the gap between raw machine learning metrics and actionable business intelligence.

---

## 🚀 Key Features

*   **Customer Explorer:** Search and filter the customer database to view individual profiles, contract details, monthly charges, and predictive risk bands.
*   **Risk Intelligence:** Visualize customer risk vs. estimated lifetime value using weighted bubble charts to instantly identify high-exposure accounts and target concentration metrics.
*   **Retention Simulator:** Dynamically simulate the financial impact of your retention team's capacity. Compare rule-based targeting (e.g., Highest Customer Value vs. Highest Expected Revenue Risk) against random sampling to optimize captured exposure.
*   **Model Insights & Explainability:** Evaluate the underlying ML pipeline (Logistic Regression, Random Forest, XGBoost). Compare cross-validated ROC-AUC, PR-AUC, Brier Scores, and Log Loss. Includes global SHAP feature-importance visualizations and out-of-fold (OOF) probability calibration curves.

## 🛠️ Tech Stack

*   **Frontend:** Streamlit, Plotly Express, Plotly Graph Objects
*   **Data Processing:** Pandas, NumPy
*   **Machine Learning:** XGBoost, Scikit-Learn
*   **Explainability:** SHAP (TreeSHAP)
*   **Styling:** Custom CSS (Cosmic Gradient Theme)

## 📂 Project Structure

*   **`app/`**: Contains the Streamlit frontend.
    *   `streamlit_app.py`: The main navigation router.
    *   `pages/`: Individual dashboard modules (`home.py`, `01_Customer_Explorer.py`, etc.).
    *   `.streamlit/config.toml`: Custom theme configuration.
*   **`notebooks/`**: Jupyter notebooks for EDA, feature engineering, model training, and explainability.
*   **`outputs/`**: Pre-computed artifacts, risk score CSVs, model evaluation metrics, and SHAP plots generated by the notebooks and consumed by the dashboard.
*   **`sql/`**: Analytical queries for base metric extraction and segment analysis.
